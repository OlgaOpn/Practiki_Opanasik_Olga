# Практические работы по ИУП — Опанасик Ольга Владимировна, 4ИСП9-45

Все работы выполнены на одном проекте — **«Добрый город»**, портал волонтёрских акций Москвы
(Python 3.13, Starlette, Jinja2; SQLite или MySQL). Преподаватель: Кондыбаева А.Б.

## Код
- [app/](app) — итоговая версия: [main.py](app/main.py) (маршруты), [core/](app/core) (БД, безопасность, формы, запросы),
  [schema_sqlite.sql](app/schema_sqlite.sql), [schema_mysql.sql](app/schema_mysql.sql), [templates/](app/templates), [static/](app/static)
- [run.py](run.py) — запуск, [seed_demo.py](seed_demo.py) — демо-данные, [requirements.txt](requirements.txt)
- [tests/test_forms.py](tests/test_forms.py) — автотест форм (МДК.05.03, задание 3)
- [check_mysql.sh](check_mysql.sh) — проверка на MySQL

Версии кода по этапам — в папках `код_этапа` работ ПР 4, ПР 11, ПР 15. Итоговая `app/` = ПР 15 + исправления по результатам тестирования (МДК.05.03).

## Запуск
```bash
pip install -r requirements.txt
python seed_demo.py     # демо-данные в свежую базу (один раз)
python run.py           # http://127.0.0.1:8000
```
По умолчанию база — SQLite (`app/dobry_gorod.db`, создаётся сама). Для MySQL:
```bash
DATABASE_URL='mysql://dobry:Dobro2026!@localhost:3306/dobry_gorod' python run.py
```
Полная проверка на MySQL (Ubuntu): `bash check_mysql.sh`.
